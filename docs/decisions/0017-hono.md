# 0017 Game-engine HTTP is Hono

- Status: accepted
- Date: 2026-08-22

## Context

[ADR 0004](0004-game-engine-typescript-onnx.md) locked TypeScript + `onnxruntime-node` but left the HTTP framework open. The engine is now being scaffolded. Compose already publishes port **3000**.

## Decision

- `game-engine` HTTP is **Hono** served with `@hono/node-server`.
- `POST /evaluate` — position JSON in, legal checker plays with evals out. Contract: [game-engine.md](../domain/game-engine.md).
- `GET /health` — liveness.
- Port **3000** remains the Compose publish port, not a framework decision.

## Consequences

Do not add Express, Fastify, or a raw `node:http` app for this API. Do not spawn Python per request. Framework choice is closed in [0000-open-questions.md](0000-open-questions.md).
